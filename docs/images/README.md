# 画面キャプチャ

ルートの `README.md` から参照している画像を置く場所です。ファイル名は README 側と対応しているので、差し替えるときは同じ名前にしてください。

| ファイル | 中身 | 撮り方 |
|---|---|---|
| `screen-standby.png` | `/screen` の待機。QR・参加コード・「第1問」 | 横長 16:9、幅1600前後 |
| `screen-answerer.png` | `/screen` に回答者名が大きく出た状態 | 同上 |
| `screen-countdown.png` | `/screen` のお手つき後のカウントダウン（`GO!` の瞬間） | 同上 |
| `player-states.png` | 参加者スマホの3状態を横に並べた1枚（待機／あなたです／ロック中） | 実機スクショを並べる |
| `host-overview.png` | `/host` の全体。進行操作・参加者一覧・問題一覧・演出の調整 | フルページ撮影、幅1400前後 |
| `song-edit.png` | 「曲を編集」で YouTube URL を貼り、曲名・アーティストが自動で入った直後 | 横長 |
| `demo-reveal.gif` | 正解発表の演出（溜め → 曲名が1文字ずつ現れる） | 3〜5秒、幅800px / 10fps / 5MB以内 |

撮影時の注意:

- **URLバーを写さない。** `/host` と `/screen` の URL には主催キーが入っています（`F11` で全画面にするのが確実）
- **実名を入れない。** 参加者名と `owner`（「◯◯さんの推し曲」）はダミーにしてください。`.gitignore` が効くのは `public/songs.json` だけで、画像に写った名前はそのままコミットされます
- シークレットウィンドウ、ブックマークバー非表示、拡張機能のアイコンが写らない状態で撮る
