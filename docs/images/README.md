# 画面キャプチャ

ルートの `README.md` から参照している画像です。差し替えるときは同じ名前で置き換えてください。

| ファイル | 中身 |
|---|---|
| `screen-standby.png` | 投影画面の待機。QR・参加コード・「第1問」 |
| `screen-answerer.png` | 投影画面に回答者名が出た状態 |
| `screen-reveal.png` | 投影画面の正解発表。曲名・アーティスト・推し曲の帯・正解者名 |
| `demo-reveal.gif` | 正解発表の演出（第1問 → 「正解は…」 → 答え）。800×500 / 12.5fps / 5.5秒 |
| `player-waiting.png` | 参加者のスマホ2台。どちらも「押す！」の待機 |
| `player-buzzed.png` | 早押しが通った瞬間。押した本人と、押せなかった人 |
| `player-locked.png` | お手つきでロックされた人と、まだ押せる人 |
| `host-overview.png` | 管理画面の全体 |

撮影・加工のときの注意:

- **URLバーを写さない。** `/host` と `/screen` の URL には主催キーが入っています（`F11` で全画面にするのが確実）
- **実名を入れない。** 参加者名と `owner`（「◯◯さんの推し曲」）はダミーにしてください。`.gitignore` が効くのは `public/songs.json` だけで、画像に写った名前はそのままコミットされます
- 投影画面は幅1600、参加者・管理画面は幅1000〜1600へ縮小しています。4Kのまま置くと1枚1.3MBほどになります
- GIF は元の4K録画のままだと26MBあったので、幅800・1コマおきに間引いて1.5MBにしています

まだ撮っていないもの:

- 曲の編集画面（YouTubeのURLを貼ると曲名・アーティスト・開始秒が自動で入るところ）
- お手つき後の `3 → 2 → 1 → GO!` のカウントダウン
