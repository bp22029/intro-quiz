# イントロクイズ 当日運用手順書

## 1. 本番までの準備

### 問題データを確定する

`public/songs.json` の4件を当日の曲へ差し替える。各項目は次の意味。

- `videoId`: YouTube URLの `v=` より後ろのID
- `title`: 答えとして表示する曲名
- `artist`: アーティスト名
- `owner`: その曲を推した人
- `startSec`: イントロを開始する秒数

曲ごとに `https://www.youtube.com/embed/<動画ID>` をChromeで直接開き、再生できることを確認する。公式チャンネルの音源を優先し、埋め込み不可に備えて代替動画も決めておく。

### Renderへデプロイする

1. GitHubへ最新のリポジトリを反映する。
2. RenderでGitHubリポジトリを連携し、Web Serviceを新規作成する。
3. Build Commandを `npm install && npm run build` にする。
4. Start Commandを `npx tsx server/index.ts` にする。
5. インスタンス数を必ず **1** にする。複数へ増やさない。
6. 一度デプロイし、発行された `https://...onrender.com` のURLを確認する。
7. 環境変数 `PUBLIC_URL` にその公開URLを設定し、再デプロイする。
8. 公開URLの `/screen` を投影PCで開き、左側のQRコードが同じ公開URLを指すことを確認する。

無料プランは15分間アクセスがないとスリープする。**出番の20分前に公開URLへアクセスして起こし、画面を開いたままにする。** 単一プロセスのメモリで早押しを管理するため、インスタンス数は当日も1のままにする。

### 人間側の必須チェック

- [ ] 4曲分のYouTube動画IDを確定した
- [ ] 4曲すべての埋め込み再生を `https://www.youtube.com/embed/<動画ID>` で確認した
- [ ] 埋め込み不可の場合に使う代替動画を用意した
- [ ] 投影PCのChromeでYouTubeへログインした
- [ ] 各曲をテスト再生し、広告が入らないことを確認した
- [ ] 投影PCの音声出力先を確認した（HDMI接続後は特に再確認）
- [ ] PCとプロジェクター側の音量を、曲とビープの両方で確認した
- [ ] Renderを出番の20分前に起こした
- [ ] QRコードを実際のスマホで読み、名前登録と早押しを確認した
- [ ] 予備として手動再生するYouTubeまたはYouTube Musicの曲順を用意した

## 2. 開演直前

1. 投影PCをプロジェクターと会場音響へ接続する。
2. Chromeで公開URLの `/screen` を開く。
3. 画面の「準備完了」ボタンを必ずクリックする。これでビープ音が許可される。
4. YouTubeモードでは表示が `4 / 4 準備完了` になるまで待つ。エラーが出た曲は本番前に動画IDを差し替える。
5. スマホ1台でQRを読み、名前を登録して試し押しする。投影画面に名前が出てビープが鳴ることを確認する。
6. `N` で次の曲へ進み、試し押しの状態を消す。必要なら `←` で第1問へ戻す。
7. YouTubeの音、ビープ、投影PCの通知音などを含め、会場で聞こえる音量を最終確認する。

## 3. キー操作

キーボード操作は投影画面 `/screen` で行う。

| キー | 動作 | 司会者の使い方 |
|---|---|---|
| `Space` | 再生 / 一時停止 | YouTubeモードで出題開始・一時停止。手動モードでは無効 |
| `1` | 正解 | 答えを表示し、YouTubeの目隠しカバーを外す |
| `2` | 誤答 | 回答者をこの曲だけロックし、受付を再開して続きから再生 |
| `R` | 押下取消 | 誤検知を取り消す。回答者はロックしない |
| `N` | 次の曲 | 答えと全員の誤答ロックを消し、次の曲を頭出しする |
| `←` / `→` | 曲選択 | 前後の曲を手動で選ぶ |
| `M` | モード切替 | YouTubeモードと手動モードを切り替える |

### 1問の進め方

1. 「第N問」を確認し、`Space` で曲を再生する。
2. 誰かが押すと曲が止まり、ビープとともに回答者名が表示される。
3. 正解なら `1`。曲名・アーティスト・推した人を表示する。
4. 誤答なら `2`。その回答者以外の早押し受付が再開する。
5. 誤って押された扱いになった場合は `R` で取り消す。
6. 答え合わせ後は `N` で次の曲へ進む。

## 4. トラブル時の逃げ道

### YouTubeが再生できない・広告が入る

すぐに `M` を押して **手動モード** へ切り替える。別ウィンドウのYouTubeまたはYouTube Musicで曲順どおりに手動再生する。参加者が押すとビープと回答者名は通常どおり出るので、ビープを聞いた操作者が手で曲を止める。手動モードでは `Space` は効かないが、`1`、`2`、`R`、`N`、矢印キーは使える。

### エラー101または150が出る

動画側が埋め込み再生を禁止している。代替の動画IDへ差し替える。すぐ直せない場合は `M` で手動モードにする。

### ビープが鳴らない

投影画面の「準備完了」ボタンをもう一度クリックし、Chromeのサイト音声、PCの音量、HDMI接続後の音声出力先を確認する。直らなければ画面の名前表示を合図に手動で曲を止める。

### スマホが接続できない

Renderの公開URLを投影PCでも開けるか確認する。スリープ復帰中なら最大1分待って再読み込みする。QRの接続先とブラウザのアドレス欄が `PUBLIC_URL` と一致することも確認する。

### スマホが途中で切れた

参加者に同じページを開き直してもらう。保存済みの名前で自動的に再参加する。戻らない場合だけ再読み込みする。
