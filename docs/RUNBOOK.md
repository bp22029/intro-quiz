# イントロクイズ 当日運用手順書

本番URL: **https://intro-quiz-u3vn.onrender.com**（以下この手順書では **BASE** と表記します）

別の環境へ置いた場合は、以下の **BASE** を読み替えてください。

| 画面 | URL | 役割 |
|---|---|---|
| ロビー | `BASE/` | 部屋を作る。参加者はここに参加コードを入れてもよい |
| 参加者 | `BASE/join/<参加コード>` | スマホで名前登録・早押し |
| 投影 | `BASE/screen/<主催キー>` | プロジェクターに表示。操作しない。曲は鳴らさない |
| 管理 | `BASE/host/<主催キー>` | 手元PCで進行をクリック操作。YouTubeモードの曲もここで鳴る |

キーボード操作はありません。進行操作はすべて手元PCの管理画面で行います。

> **管理画面のURLが唯一の資格です。** ログインが無いので、これを失うと部屋に戻れません（作り直しになります）。作った直後にブックマークするか、管理画面の「管理URLをコピー」で控えてください。**参加者に渡すのは参加用URL（`BASE/join/<参加コード>`）だけです。管理URLと投影URLを渡すと答えが見えます。**

## 開演前の準備

### 1. Renderを起こして部屋を作る — 出番の20分前

1. 本番URL `BASE/` を開く。
2. スリープからの復帰中は表示まで30秒〜1分ほど待ち、必要なら再読み込みする。
3. 「新しい部屋を作る」を押す。管理画面へ移り、上部に参加コードと参加URLが出る。
4. **管理画面のURLをブックマークする。** 以後この部屋に戻る手段はこのURLだけ。
5. 以後は本番終了まで画面を開いたままにする。**サーバーが再起動すると部屋は消える**ので、作り直して参加コードを配り直すことになる。

**部屋を作るのは出番の直前で構いません。** 誰も繋いでいない部屋は2時間で片付けられるため、前日に作っておくことはできません。

### 2. 投影PCを準備する

1. 投影PCをプロジェクターと会場の音声出力へ接続する。
2. 投影画面を開く。**必ず管理画面の「投影画面を開く」ボタン**から開く（主催キー入りのURLを手で打たなくてよい）。開いたら投影用ディスプレイへ移して全画面にする。
3. 「投影を開始する」をクリックする。確認のビープが鳴ることを確かめる。このクリックをしないと、早押し時のビープやYouTube音声がブラウザに止められることがある。
4. プロジェクターにQRコード、**参加コード**、問題番号、参加者欄が見えていることを確認する。QRが読めない席の人には、この参加コードを読み上げて `BASE/` から入ってもらう。
5. **金色が意図どおりに出ているか、投影して目で確かめる。** プロジェクターの色温度によって、金は黄色寄りにも茶色寄りにも転ぶ。暗すぎて読めないようなら会場の照明を落とす。
6. 投影画面は曲を鳴らさない。曲の音は管理画面を開いたPCから出る。
7. **全画面にする前にURLバーを隠す。** 投影URLには主催キーが入っているので、映すと参加者が投影画面（＝答えが見える画面）を開けてしまう。

投影画面は表示専用です。投影画面でキーを押しても進行操作はできません。

### 3. 手元PCの管理画面を準備する

1. **Chromeのプロファイルを確認してから**管理画面を開く（手順1でブックマークしたURL）。**曲を再生するのはこのブラウザ**なので、YouTube にログインしているアカウントが本番で使うものになっていること。Music Premium 限定の曲は、アカウントが違うと鳴らない。
2. 「操作をはじめる」をクリックする。確認のビープが鳴ることを確かめる。（このビープは音が出るかの確認用。早押しのときは管理画面は鳴らない。）
3. 左上が緑の「接続中」になっていることを確認する。**参加コードと曲名が出ていることも必ず見る。** ここが空のままなら、サーバーから状態を受け取れていないので画面を再読み込みする。
4. **画面の幅を広げる。** 1280px 以上あると2列になり、本番中に押すボタンがスクロールせずに全部見える。狭いと1列になり、操作を探してスクロールすることになる。
5. 再生モードが既定の「YouTube」になっていることを確認する。プレイヤー欄が「準備完了」になり、再生ボタンが押せるまで待つ。
6. 手動モードでは、管理画面を画面の左側、YouTubeを右側または別ウィンドウに置くと操作しやすい。
7. 手動モードの曲は手元PCから鳴るため、手元PCも会場音響へ出力できることを確認する。

### 4. 開演前テストをする

1. スマホ1台で投影画面のQRコードを読み、名前を入れて参加する。
2. 早押しボタンを押す。
3. 投影画面と管理画面に回答者名が表示され、投影画面でビープが鳴ることを確認する。（早押しのビープは投影画面だけが鳴らす。同じPCで両方が鳴ると重なって聞こえるため。）
4. 管理画面の「押し直し」をクリックし、ロックせず受付中へ戻ることを確認する。
5. もう一度押し、「× お手つき」で不正解表示と `3 → 2 → 1 → GO!` のカウントダウンを確認する。
6. 「この問題をやり直す」をクリックして、試験で付いた押下・答え表示・お手つきロックをすべて消す。
7. 参加予定のスマホがQRから接続できることと、管理画面の参加人数が増えることを確認する。

## 再生モード

管理画面右上のトグルで「手動」と「YouTube」を切り替えます。既定は **YouTubeモード** で、通常はこちらで進行します。切り替えると、それまで鳴っていたものは止まります（手動タブが鳴ったままYouTubeモードへ移って二重に鳴る、という事故を防ぐため）。

**手動モードは逃げ道です。** 埋め込みでは原理的に鳴らせないものがあるために残しています。

- **年齢制限つき動画**は埋め込みが完全にブロックされる。`embeddable` が真でも鳴らないので、事前チェックでは見抜けない
- 埋め込み禁止（エラー101 / 150）の動画
- YouTube 側の仕様変更。実際に2025年末の Referer 必須化（エラー153）を踏んでいる

当日、YouTubeモードで鳴らない曲に当たったら、迷わず手動モードへ切り替えてください。

### 手動モード（逃げ道）

- 事前に「再生タブを用意」をクリックして、曲再生用のタブを開いておく。
- 管理画面の「▶ イントロ (N秒〜)」をクリックすると、そのタブが `startSec` から再生する。2回目以降はタブが切り替わらず、管理画面からフォーカスが外れない。
- **早押しのビープを聞いたら、操作者が再生タブへ移って手で止める。** 手動モードで人の手が要るのはここだけ。
- 「○ 正解・答えを出す」を押すと、「サビを鳴らすまで」に設定した秒数の後、同じタブが `chorusSec` から再生する（自動サビ再生をオフにもできる）。
- 手動でサビへ飛ばす場合は「♪ サビ (N秒〜)」をクリックする。
- **これらのボタンは手動モードのときだけ出る。** YouTubeモードでは画面内のプレイヤーが鳴らすので、外部タブを開くボタンは表示されない。
- **問題を移ると（「前の問題」「次の問題」「問題一覧のクリック」「この問題をやり直す」）、再生タブは自動で無音になる。** 正解発表で鳴らしたサビを手で止める必要はない。タブ自体は残るので、次の曲もそのまま使い回せる。
- 答え表示やお手つき判定は、通常どおり管理画面のボタンで行う。

### YouTubeモード（既定）

- 曲の再生は**管理画面に埋め込まれたプレイヤー**が担当する。別の窓を開く必要はない。
- 音は管理画面を開いたPCから出る。そのPCの音声出力先と音量を確認する。
- 全曲の準備が終わるまで再生ボタンは押せない。「動画を準備中… N / M」の間は待つ。
- 管理画面の「▶ イントロ再生」と「⏸ 一時停止」で操作する。
- 参加者が押すと自動で一時停止する。
- 「○ 正解・答えを出す」を押すと、**その瞬間から助走が鳴り出す。** 「正解は…」の長さに設定した秒数ぶんサビの手前から、**音量を上げながら**再生するので、溜めが明けて答えが出る瞬間に、ちょうどサビの頭が来る。
- 「正解は…」の長さを変えると助走の長さも変わる。長くすると曲が先に聞こえる時間が延びるので、2秒前後が扱いやすい。
- 助走は「演出の調整」の**「『正解は…』の溜めから助走を鳴らす」**で切れる。切ると溜めは無音になり、答えが出てからサビへ飛ぶ（従来の演出）。会場の雰囲気に合わせて当日その場で選べる。
- **お手つきの `GO!` で、止めた位置から自動で再開する。** 押し直す必要はない。「押し直し」でも同じく再開する。
- 答えを出した後、再生ボタンの文言は「⏸ サビを止める / ▶ サビを再生」に変わる。鳴っているのがイントロではなくサビだからで、押せば実際にサビが止まる。
- 再生できない曲はプレイヤー欄に赤く理由が出る。その曲は手動モードで流す。
- **音量は「全体音量」→「この曲」の順に合わせる。**
  1. 「演出の調整」の**全体音量**（既定70）で、会場全体の大きさを決める。曲ごとの設定を持たない曲はすべてこの値で鳴るので、1曲ずつ触る必要はない。
  2. それでも目立つ曲だけ、プレイヤー下の**「この曲」**を鳴らしながら動かす。離すとその曲に保存される。「全体に戻す」で上書きを取り消せる。
- YouTube は大きい音を下げるだけで小さい音は持ち上げないため、アートトラック（「〇〇 - Topic」）とMVを混ぜると音量差が残る。**本番前に全曲を鳴らして揃えておく。**
- モードを切り替えた直後は全曲のプレイヤー準備に少し時間がかかることがある。本番前に全曲を試す。

## 1問の進行手順

1. **問題を選ぶ。** 管理画面の「前の問題」「次の問題」または画面下の問題一覧をクリックする。問題を選ぶと、前の押下・答え表示・お手つきロックは解除される。
2. **イントロを再生する。**
   - 手動モード: 外部のYouTubeを `startSec` の位置から手で再生する。
   - YouTubeモード: 「▶ イントロ再生」をクリックする。
3. **早押しを待つ。** 最初の1人だけが受理される。投影画面でビープが鳴り、投影画面と管理画面に回答者名が出る。YouTubeモードでは自動停止する。手動モードではビープを合図に再生タブを手で止める。
4. **回答を判定する。**
   - 正解: 「○ 正解・答えを出す」をクリックする。投影画面に「正解は…」が出て、溜めのあいだにサビへ向けた助走が鳴り、溜めが明けると曲名・アーティスト・推した人・正解者が表示される。手動モードでは再生タブが `chorusSec` から鳴る（「♪ サビ (N秒〜)」で手動でも飛ばせる）。
   - お手つき: 「× お手つき」をクリックする。回答者はその問題だけロックされ、全画面に不正解と3秒カウントダウンが出る。`GO!` が出たら他の参加者の受付が再開する。曲も続ける場合は、手動モードなら外部YouTubeを手で再開し、YouTubeモードなら「▶ イントロ再生」をクリックする。
   - 誤検知・押し間違い: 「押し直し」をクリックする。回答者をロックせず、すぐ受付中へ戻る。**押される直前に曲が鳴っていたなら、止めた位置から自動で再開する。**
5. **次の問題へ進む。** 答え合わせが終わったら「次の問題」をクリックする。全員のお手つきロックと表示が消え、次の問題へ移る。手動モードでは、鳴っていたサビもここで自動的に止まる。

同じ問題を最初からやり直す場合は「この問題をやり直す」をクリックします。現在の問題番号は変えず、押下・答え表示・全員のお手つきロックを解除し、**曲もイントロの頭で止め直します**（手動モードでは再生タブを黙らせます）。

## 参加者とお手つきの扱い

- 参加者はスマホのブラウザに保存された `clientId` で識別される。
- お手つきした参加者がページを再読み込みしたり名前を変えたりしても、その問題のロックは解除されない。
- 同じ表示名で別ブラウザから入り直した場合も、その問題ではロックされる。
- ロックは「次の問題」「前の問題」、問題一覧での選択、または「この問題をやり直す」で解除される。
- 管理画面の参加者一覧では、名前をクリックして個別のお手つきロックを付け外しできる。別ブラウザからの入り直しなどを司会が手動で処理するときに使う。
- スマホが一時的に切れた場合は同じページを開き直す。保存済みの名前で自動復帰する。

## `songs.json` の書き方

問題データは `public/songs.json` にJSON配列で記述します。コメントや末尾の余分なカンマは入れません。

これは**新しい部屋に配られるひな形**です。サーバーの起動時に1度だけ読み込まれるので、書き換えたらサーバーを再起動し、部屋を作り直してください。既に開いている部屋には反映されません。デプロイ先では `songs.json` を置けないので、下記「管理画面から曲を足すのが速い」の書き出し／読み込みを使います。

```json
[
  {
    "videoId": "dQw4w9WgXcQ",
    "title": "曲名",
    "artist": "アーティスト名",
    "owner": "曲を推した人の名前",
    "startSec": 0,
    "chorusSec": 43
  }
]
```

| 項目 | 内容 |
|---|---|
| `videoId` | YouTube URLの `v=` より後ろにある動画ID |
| `title` | 答えとして投影する曲名 |
| `artist` | 答えとして投影するアーティスト名 |
| `owner` | 曲を推した人の名前。画面側で「さんの推し曲」が付く。**空にすればその帯ごと出ない** |
| `startSec` | イントロ再生を開始する位置（秒） |
| `chorusSec` | サビの位置（秒）。正解時、「正解は…」の長さぶん手前から鳴り出し、答えが出る瞬間にここへ到達する |
| `volume` | この曲だけの音量（0〜100）。**省略すると全体音量に従う**。管理画面のスライダーで調整できる |

`chorusSec` を省略した場合、YouTubeモードの正解時は `startSec` から再生されます。実運用では全曲に設定してください。

### 管理画面から曲を足すのが速い

1. YouTubeで曲を開き、サビの位置で一時停止する。
2. 「共有 → 現在の時間から」にチェックを入れてURLをコピーする。
3. 管理画面の「曲を編集」→「＋ 曲を追加」→ **動画ID欄にそのURLを貼る。**
4. 動画ID・サビ開始秒・曲名・アーティストが入る。曲名とアーティストは動画タイトルから起こした下書きなので、目で見て直す。
5. 「推した人」だけ手で入れる。
6. 「反映する」を押す。この時点で曲リストは管理画面のブラウザにも控えられる。
7. 「JSONとして書き出す」でテキストとして保存しておく。**サーバーは曲を保存しないので、これが持ち出し手段になる。** 別のPCや翌年の会では「JSONから読み込む」で戻せる。

曲名が思うように入らないときは「YouTubeから曲名を取得」を押すと、入力済みの内容も上書きして取り直します。埋め込みが禁止されている動画なら、ここで「この動画は埋め込みが禁止されています」と出ます。

### YouTube埋め込みを確認する

**`https://www.youtube.com/embed/<videoId>` をアドレスバーに直接貼る方法は使えません。**
YouTube は 2025年末から、埋め込みプレーヤーが HTTP Referer で自分を名乗ることを必須にしました。
アドレスバーから開くと参照元ページが無いため referrer が付かず、**埋め込みが許可されている動画でも必ず「エラー153 動画プレーヤーの設定エラー」になります。**
153 は埋め込み禁止の意味ではないので、これを根拠に曲を外さないこと。

代わりに次の2つで確認します。

**1. 確認ページで全曲まとめて見る（推奨）**

**必ず本番で使うChromeプロファイルで開くこと。** 「プレイヤー」欄の結果はログイン中のGoogleアカウントで変わるので、別プロファイルで全部緑にしても本番では鳴らないことがある。

サーバーを起動して `/embedcheck.html` を開く（例: `http://localhost:3000/embedcheck.html`）。
`songs.json` の全曲について、埋め込み設定と実際の再生可否を一覧で出します。本物のページとして読み込まれるので referrer が付き、正しく判定できます。映像も出るので `startSec` と `chorusSec` の位置確認も同時にできます。

- 「200 許可」かつ「読み込みOK」→ 使える
- 「401 埋め込み禁止」→ 代替の動画へ差し替える
- 「この環境では再生できません」(101 / 150) → **まずChromeのアカウントを疑う。** Premium 限定・地域・年齢の制限でも同じコードが返る。アカウントが正しければ代替の動画へ差し替える
- 「404 動画が無い」→ 動画IDの誤りか、非公開・削除

**2. 1曲だけ手早く見る**

アドレスバーに次を貼る。referrer と無関係のHTTP APIなので、この変更の影響を受けません。

```
https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=動画ID&format=json
```

JSONが出れば埋め込み可、`401` なら埋め込み禁止、`404` なら動画が無い。
ただし oEmbed は埋め込み設定しか見ないので、**年齢制限と地域制限は見抜けません**。実際に使う曲は必ず1の確認ページを通してください。

**曲を選ぶときの注意**

1. 公式チャンネルか「〇〇 - Topic」（アートトラック）の動画を優先する。アートトラックは YouTube が自動生成して管理しており、埋め込み設定が既定のままなので通りやすい。
2. `startSec` と `chorusSec` の位置が意図した箇所か、通常のYouTube画面でも確認する。
3. 広告の有無と、**本番で使うアカウントでの**再生可否を確認する。
4. 埋め込み不可に備え、各曲の代替動画を用意する。
5. 変更を本番へ反映した後、管理画面をYouTubeモードへ切り替え、全曲を実際にテストする。

## トラブル時の逃げ道

### YouTubeモードで曲が再生できない・埋め込みエラーが出る

**まずChromeのGoogleアカウントを疑う。** Music Premium 限定の曲は、Premium のアカウントなら鳴り、別のアカウントでは「この動画を視聴できるのは Music Premium のメンバーのみです」で止まる。プロファイルを切り替えただけで直ることがある。事前チェックを別プロファイルで通していると気づきにくい。

管理画面右上のトグルを **「手動」** に切り替える。「▶ イントロ (N秒〜)」で再生タブに曲を出し、以降は再生を管理画面から、停止を手で行う。早押し、ビープ、回答者表示、正解表示、お手つきは手動モードでもそのまま動く。

エラー101または150は、その動画が埋め込み再生を禁止している。代替の `videoId` へ差し替えるか、手動モードで続行する。

エラー153は意味が違う。埋め込みプレーヤーへ HTTP Referer が届いていない状態で、**全曲が同時に153になる**のが特徴。曲の問題ではないので差し替えても直らない。手動モードへ切り替えて進行を続け、原因（ブラウザの拡張機能、リバースプロキシやセキュリティソフトが `Referrer-Policy` を書き換えている等）は本番後に調べる。

### 広告が入る・イントロの頭が欠ける

すぐ手動モードへ切り替え、事前に用意した動画を外部YouTubeで頭出しして使う。進行を止めて埋め込み側を直そうとしない。

### ビープが鳴らない

早押しの効果音は **投影画面だけが鳴らす**（管理画面は鳴らさない）。管理画面から音が出ないのは正常。管理画面の「演出の調整」→「早押しの音」の**試聴**で、音そのものが出るかを先に確かめられる。なお**参加者の端末では鳴らない**（そういう作り）。

1. 投影画面を再読み込みする。
2. 投影画面は「投影を開始する」、管理画面は「操作をはじめる」をもう一度クリックする。
3. Chromeのサイト音声、PC音量、HDMI接続後の音声出力先を確認する。
4. 直らない場合、管理画面の回答者名表示を合図に手で曲を止める。

### お手つきを誤って付けた

すぐ受付からやり直す場合は「この問題をやり直す」をクリックする。3秒演出を打ち切り、その問題の全員のロックを解除して受付中へ戻る。演出後に特定の1人だけを解除する場合は、管理画面の参加者一覧で「お手つき」と表示された名前をクリックする。

### YouTubeモードなのに音が出ない

1. 再生ボタンが「動画を準備中… N / M」のままでないか確認する。準備が終わるまで待つ。
2. プレイヤー欄に赤い「この曲は再生できません」が出ていないか確認する。出ていれば手動モードへ切り替える。
3. 管理画面を開いたPCの音声出力先と音量を確認する。
4. **管理画面を裏のタブに隠したまま操作していないか確認する。** Chrome は隠れている画面で開始された再生を、前面に来るまで延期する。管理画面を見ながら操作していれば起きない。
5. それでも鳴らなければ手動モードへ切り替える。

### 管理画面が「再接続中」になった

ネットワークを確認し、数秒待つ。戻らなければ管理画面を再読み込みし、「操作をはじめる」をクリックする。サーバーが再起動していなければ、問題と早押しの状態はサーバーから再取得される。

### 「部屋が見つかりません」と出た

部屋はサーバーのメモリにしか無い。**サーバーが再起動すると全部消える。** 誰も繋いでいない状態が2時間続いたときも片付けられる。

`BASE/` から部屋を作り直す。**参加コードは新しくなるので、投影画面のQRを出し直し、参加者にはスマホを開き直してもらう。** 曲リストは下の「Renderが再起動した」の手順で戻す。

### Renderが再起動した

部屋ごと消えるので、`BASE/` から作り直す。**曲リストも初期値に戻る。** 管理画面に「前回この端末で使った曲リストがあります」と出るので「前回のリストに戻す」を押す。出ない場合は「JSONから読み込む」で書き出しておいたものを貼る。投影画面を開き直して「投影を開始する」を押し、参加者には新しいQRを読み直してもらう。管理画面で問題を選び直して再開する。

### 管理画面のURLが分からなくなった

**戻る手段は無い。** `BASE/` から部屋を作り直し、曲リストを上の手順で入れ直して、参加者に新しいQR・参加コードを配り直す。作ったら真っ先にブックマークすること。

### スマホが参加できない

1. 投影PCと手元PCで本番URLが開くか確認する。
2. Renderの復帰中なら最大1分待って再読み込みする。
3. QRコードの接続先が `BASE/join/<参加コード>` になっていることを確認する。
4. 参加者にはQRを読み直してもらう。読めない場合は `BASE/` を開いて**参加コードを手で入れてもらう**（投影画面にQRの下に大きく出ている）。
