# テストと検証

`scripts/` に、実際に Socket.IO で繋いで振る舞いを検証するスクリプトを置いています。テストランナーは入れていません。**本物のサーバーに本物のクライアントとして繋ぎ、画面がやることをそのまま再現する**方式です。早押しの排他や答えの非配布は、単体テストではなく「同時に繋いだ2人のうち1人だけが通るか」でしか確かめられないためです。

引数を省略すると `http://localhost:3000` に接続します。

| スクリプト | 検証内容 |
|---|---|
| `buzztest.mjs` | 同時押しで1人だけ受理、お手つきロック、3秒後の受付再開、押し直し、未登録の拒否 |
| `roomtest.mjs` | 別々の部屋が干渉しないこと。早押し・参加者・お手つき・進行状態・曲リストが混ざらず、参加コードでは答えを受け取れないこと |
| `hosttest.mjs` | 管理画面の操作が投影状態へ反映されるか、後から繋いだ画面への状態同期 |
| `relocktest.mjs` | 切断・再接続・名前変更をしてもお手つきが解除されないこと |
| `leaktest.mjs` | 参加者に答え（曲名・アーティスト・推した人）が配信されていないこと。役割を名乗っても受け取れないこと |
| `cleartest.mjs` | 「参加者を全員クリア」で、離脱者だけが消えて接続中の人は戻ること |
| `songstest.mjs` | 管理画面からの曲リスト編集が各画面へ配られること、曲ごとの音量が保存され範囲外の値が丸められること |
| `resumetest.mjs` | お手つきのカウントダウン後に曲が再開すること、鳴っていなかった曲は再開しないこと、演出を打ち切ったら再開しないこと |
| `sweeptest.mjs` | 誰も居なくなった部屋が片付けられること、人が居るあいだは残ること（**引数を取らず、寿命を短くした検証用サーバーを自分で起動します**） |
| `urltest.ts` | YouTube URLからの動画ID・開始秒の抽出（サーバー不要。`npx tsx` で実行） |
| `routetest.ts` | URLから部屋と立場（参加者・投影・管理）を読む処理（サーバー不要。`npx tsx` で実行） |
| `fittest.ts` | 投影画面の大きな文字を枠に収める計算。曲名の割れ方とはみ出し、字幅の実測と見積もりへの退避（サーバー不要。`npx tsx` で実行） |
| `metatest.ts` | 動画タイトルからの曲名・アーティストの取り出し（サーバー不要。`npx tsx` で実行） |
| `importtest.ts` | 貼り付けたJSONの読み込みと、壊れた入力の弾き方（サーバー不要。`npx tsx` で実行） |
| `loadtest.mjs` | 同時接続を増やしたときの早押し応答時間の計測 |


## 実行のしかた

```bash
npm start                              # 別ターミナルでサーバーを起動しておく
node scripts/buzztest.mjs
node scripts/roomtest.mjs
node scripts/loadtest.mjs http://localhost:3000 30
node scripts/sweeptest.mjs             # これだけサーバーを自分で立てる（引数なし）
npx tsx scripts/routetest.ts           # .ts は tsx で実行（実装を直接importするため）
```

**各スクリプトは実行のたびに自分専用の部屋を作ります。** ブラウザで別の部屋を開いたままでも影響しません（他の部屋の参加者は人数に入らないため）。

リモート環境に対して実行する場合は第1引数にURLを渡します。環境変数 `D` で各確認の待ち時間をミリ秒指定できます（遅い環境向け）。

```bash
D=1500 node scripts/hosttest.mjs https://<デプロイ先のホスト>
```

**これらのスクリプトは部屋を作り、参加者の追加・問題選択・モード変更を実際に行います。** 操作は自分の部屋の中だけで完結しますが、本番進行中のサーバーではCPUと部屋数を消費するので避けてください。

## サーバーに手を入れたら

最低限 `roomtest.mjs`（部屋の独立）と `leaktest.mjs`（答えの非配布）を通してください。この2つが、公開して運用するうえでの前提そのものを守っています。型だけの確認は `npm run typecheck` です。
