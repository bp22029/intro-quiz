# 効果音の置き場

早押しなどの**効果音ファイル**をここに置きます。ここに置いたファイルはビルド時に
`dist/sfx/` へコピーされ、`/sfx/<ファイル名>` で配信されます。

**楽曲そのもの（問題に使う mp3 など）は置かないでください。** 曲は YouTube から
再生します。ここに入れてよいのは、早押し音のような短いUIの効果音だけです。

## 収録しているファイル

| ファイル | 用途 | 元の素材名 | 出所 | ライセンス |
|---|---|---|---|---|
| `buzz-click.mp3` | 早押し（押し込む物理音あり） | クイズ早押しボタン1 | [効果音ラボ](https://soundeffect-lab.info/) | 商用無料・報告不要・クレジット表記任意 |
| `buzz-tone.mp3` | 早押し（物理音なしの電子音） | クイズ早押しボタン2 | [効果音ラボ](https://soundeffect-lab.info/) | 同上 |

効果音ラボは効果音ファイルそのものの再配布を禁じていますが、**このリポジトリの
使い方は再配布に当たらない**ことを [FAQ](https://soundeffect-lab.info/faq/) で
明示しています。

> 「効果音を入れたアプリをGithubで公開する際、音源ファイルむき出しでも良いですか？」
> 「問題ございません。（略）当サイトではこのケースを再配布とみなしません」

ただしこれは「**アプリの操作音として組み込む**」場合の話です。効果音を自由に鳴らせる
アプリ（効果音集）を作ることは再配布に当たり、禁止されています。この線を越えないように
してください。

## 置き足すときに守ること

- **短いこと。** 早押しの合図は0.3秒前後。長いと次の操作に被る
- **形式は `.mp3` か `.wav`。** どのブラウザでも鳴る
- **ファイル名は ASCII で、役割が分かる名前にする。** 日本語名はURLの扱いが面倒になる
- **上の表に出所とライセンスを必ず書く。** 公開リポジトリなので、再配布してよい条件の
  ものだけを置くこと。判断できない素材は置かない
- 選択肢として出すなら `src/types.ts` の `BuzzSound` に追加し、`src/beep.ts` の
  `SFX_URL` にURLを書く

## 鳴らない場合の逃げ道

読み込みに失敗しても進行は止まりません。ファイルが取得できないときは、
Web Audio で組み立てた合成音（[../../src/beep.ts](../../src/beep.ts)）が鳴ります。
当日ファイルが壊れていても、無音にはなりません。管理画面から「合成音」を
明示的に選ぶこともできます。
